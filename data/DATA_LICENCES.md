# Data in this folder
- `uci_activity_older_adults.zip`: UCI ML Repository dataset 427, "Activity recognition with healthy older people using a batteryless wearable sensor" (Torres et al., 2013), licence CC BY 4.0 (as stated in the course book, ch10a2). Unmodified copy. https://archive.ics.uci.edu/dataset/427
- `mobility_aids_manifest.csv`: list compiled for this course of 72 Wikimedia Commons images with licence, author and source URL. Images are not stored here; the loader downloads them from Commons.
